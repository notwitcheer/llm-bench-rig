Task:
Implement the flocking model of the August 2026 arXiv paper "Impact of Higher-Order Interactions on Collective Motion" (Masoumi, Kargaran, Jafari; https://arxiv.org/abs/2608.10844) as a browser demo that shows two flocks side by side under the same noise: the standard Vicsek model (SVM, pairwise alignment) on the left and the paper's higher-order Vicsek model (HOVM, triadic alignment) on the right. Follow the method below; it is the paper's method, with the neighbour set made exact. The page must include:
1. Setup. N = 1000 birds per panel (URL parameter N overrides it), a square box of side L = sqrt(N / rho) with rho = 10 (so L = 10 for N = 1000) and periodic boundaries, speed v0 = 0.03 per time step, interaction radius R = 1, time step 1. Bird i has a heading theta_i and the unit vector u_i = (cos theta_i, sin theta_i). Each time step is synchronous: first compute every bird's new heading from the headings and positions at the start of the step, then set all headings, then move every bird x_i += v0 * (cos theta_i, sin theta_i) with its NEW heading and wrap into [0, L). The neighbours of bird i are the OTHER birds j != i whose periodic (minimum-image) distance to i is below R. Bird i itself is never one of its own neighbours in the triadic sum below.
2. SVM (left panel). The aligning direction is the mean unit vector of bird i and its neighbours: m_i = (u_i + sum over neighbours u_j) / (1 + n_i), with n_i the number of neighbours. New heading theta_i' = atan2(m_i) + eta * (r - 0.5), r uniform in [0, 1) drawn fresh for every bird and every step (eta is the noise amplitude; the noise is a uniform angle between -eta/2 and +eta/2 radians).
3. HOVM (right panel, the paper's alpha = 0 limit). For bird i with neighbours N_i (excluding i, see 1) and n_i = |N_i|, take every unordered pair of distinct neighbours {j, k} (there are n_i (n_i - 1) / 2 of them) and sum the vector (u_j . u_i) u_k + (u_k . u_i) u_j over all pairs, then divide by the number of pairs: h_i = (1 / T_i) * sum over pairs {j,k} of [ (u_j . u_i) u_k + (u_k . u_i) u_j ], T_i = n_i (n_i - 1) / 2. If n_i < 2 then h_i = 0. The new heading is theta_i' = atan2(h_i) + eta * (r - 0.5) with the same noise as in 2; if |h_i| is below 1e-12 the bird keeps its current heading before the noise is added. (Cost note: the sum over all pairs can be computed per bird in O(n_i) from S = sum_j u_j, D = sum_j (u_j . u_i) and W = sum_j (u_j . u_i) u_j: the pair sum equals D * S - W. Use it or loop over pairs, both are fine for N = 1000.) HOVM is the same model as SVM except for the aligning direction; both panels use the same eta, the same seed and the same initial positions and headings.
4. Order parameter phi = |sum_i u_i| / N, 1 for a perfectly aligned flock and about 1/sqrt(N) for random headings. Show phi for both panels live.
5. Start state: by default all birds start with heading 0 (an ordered flock) at random positions drawn from the seed; start=random draws random headings instead.
6. Opened with no parameters the page starts at once with eta = 1.0, seed 1, N = 1000 and runs several simulation steps per frame so the flocks visibly move. Keys: Up / Down change eta by 0.1 (0 to 5), Space pauses or resumes, R restarts from the seed, S toggles a slow automatic noise ramp from the current eta up to 3.0.

The paper's main claim, which your page must show: noise eta fights the alignment. For the pairwise SVM the order falls smoothly as eta grows. For the triadic HOVM the order stays high at low noise and then breaks down abruptly (a discontinuous, first-order transition) at a lower noise than SVM, so at a noise where the SVM flock is still clearly ordered the HOVM flock has fallen apart into a disordered gas.
Before you finish, check the claim on your own simulation: with window.flockRun, seed 1, ordered start, 1500 steps and avg 300, run eta = 1.0 and eta = 2.2. At eta = 1.0 both models must be clearly ordered (phi above 0.6). At eta = 2.2 the SVM must still be clearly ordered while the HOVM must have collapsed to a disordered state (phi below about 0.2, far under the SVM's). Also check that other seeds give the same picture: the effect must come from the model, not from one lucky seed. If it does not hold, find the bug in the method (which birds are neighbours, what the triadic sum runs over and how it is normalised, the noise term, the synchronous update); never special-case eta values or seeds.
